# Codex 任务：7 位角色 Q 版像素风资产标准化

## 目标
基于 7 张已有角色三视图原画，为每位角色制作保留识别特征的 Q 版像素角色素材，并把现有 ChatGPT 生成的第一轮像素三视图当作视觉参考，而不是最终必须照搬的生产级 sprite。产出可供偶像陪伴产品界面、互动场景和角色动画使用的规范化素材。

**当前状态：** 此仓库的任务文本已提交；原始 PNG 和 ChatGPT 生成 PNG 尚未通过 GitHub 连接上传。请先取得用户提供的图像文件（见 `ASSET_MANIFEST.md`），绝不可假装这些图片已存在于仓库中。没有原图时，可先实现资产处理、质检和目录工具，但不要凭空重绘特定角色。

## 艺术与输出规范
1. 统一 Q 版比例，建议头高约占整个人物高度 35–45%，但允许为双辫、蓬松卷发等保持辨识度略调比例；同一角色三视图身高及头体比例一致，七位角色视觉尺度统一。
2. 采用**真正的像素表现**：清晰像素网格、有限而协调的颜色阶、清晰外轮廓，不要仅仅在高清插画表面加马赛克或模糊滤镜。
3. 每人提供正面、严格侧面、背面完整站姿；尽量统一朝向（侧面朝左），脚底对齐；所有饰品在各视图之间保持逻辑一致。
4. 输出透明背景 RGBA PNG 单视图（无伪透明白底），正侧背三视图拼图，必要时提供适用于界面的预览图。不要裁切头发、脚或配件。
5. 建议先把单人绘图控制在约 128×192 或 192×256 的逻辑画布，并以最近邻放大至 2× / 4× 用于展示；实际规格可随团队产品需要调整并记录，不要把建议尺寸误当既定尺寸。
6. 路径规范：`character-pixel-task/outputs/{Character}/{front,side,back}.png`、`turnaround.png`；七人总览 `character-pixel-task/outputs/all-characters-preview.png`。
7. 不向生成图添加角色名水印或不必要徽标；保留原图确有的标志性配饰，但无需追求不可读的微小品牌字样。

## Codex 可直接执行的开发任务
- [ ] 核对 `references/` 的 7 张原图及 `generated/` 的 7 张初版像素稿是否齐全；若缺失，准确报缺失列表。
- [ ] 编写可重复执行的 Python / Pillow 素材处理脚本：尺寸规范、最近邻缩放、透明像素检测、视图切割（仅在图片排布确认后）、文件命名和精灵图排布；不要将去白底当作已完成的高质量抠图。
- [ ] 定义资产清单 JSON（角色 ID、来源图、输出路径、朝向、逻辑画布尺寸），并实现最少一组自动校验。
- [ ] 对现有生成图与原图做人工/视觉核对，形成每人的偏差清单，然后使用可用且获授权的图像生成或绘制能力迭代修正；**Codex 本身的代码能力不等于一定具备图像生成接口**。缺少图像服务时保留可执行提示词及待办，不伪称已重绘。
- [ ] 输出角色总览，并用前后视图检查头发长度、衣服背面和鞋靴连续性。
- [ ] 在 README 记录运行命令、必要依赖、素材来源、完成状态及未完成事项。

## 验收标准
七个不同角色；每人 3 个完整视图（21 张单视图）、7 张三视图合成、1 张七人总览；识别特征无混用；透底素材 alpha 有效；所有 PNG 路径与资产清单一致；自动验证报告真实通过。任何缺少原始图、模型调用权限或人工确认的步骤应标记为 blocked / pending，不编造结果。

## 优先级
P0 保留身份及服装准确性 > P1 同套风格与三视图一致 > P2 透明背景和可用像素资产 > P3 自动化流程与多分辨率导出。
